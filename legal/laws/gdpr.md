# GDPR Compliance Notes

- **Scope:** Applies to EU residents interacting with Codex-Agent artifacts.
- **Data Categories:** Project metadata, contributor handles, audit logs.
- **Key Controls:**
  - Data minimization (store only operational logs).
  - Right-to-erasure process documented via `audit/logs/` entries.
  - Incident response within 72 hours, coordinated with Legal + Compliance.
- **Open Tasks:** Define DPA template once external data processors connect.
