# Deployment Plan (DPD) Template

1. **Overview & Objectives**
   - Feature / service name
   - Success metrics

2. **Infrastructure Diagram**
   - Diagram link or description
   - Components, environments, dependencies

3. **Rollback Strategy**
   - Trigger conditions
   - Steps to revert + owners

4. **Test & Validation Plan**
   - Test matrix (unit, integration, security)
   - Evidence links (logs, screenshots)

5. **Approval Sign-off**
   - Product Lead: ___
   - Engineer Lead: ___
   - Legal/Compliance: ___
   - Finance (if budget impact): ___

> Attach completed plan to release PR and reference in `reports/releases/summary/`.
