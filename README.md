# Codex-Agent (Main Branch)

This branch remains stable while we test whether Codex-Agent can govern an end-to-end software-production workflow. Active work streams live on the `dev` branch.

## View Work in Progress
1. Clone the repository and switch to `dev`:
   ```bash
   git clone <repo-url>
   cd codex-agent
   git checkout dev
   ```
2. Create feature branches from `dev`, open PRs back to `dev`, and promote to `main` only after validation/tagging.

## What You Can Expect Here
- High-level documentation and previously released artifacts.
- Links to downstream projects (e.g., hello-agent) and governance templates.
- Release tags that have already passed the review pipeline.

If you landed on `main` and want the status of the hello-agent pilot, please switch to `dev` or review the latest release summaries under `reports/releases/`.
