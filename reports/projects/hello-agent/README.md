# hello-agent — Staff Report Instructions

All core stakeholders (Product, Engineering, Finance, HR, Compliance) must file a **short personal report** after each major milestone (e.g., MVP delivery, release tag).

## Required Sections
Use `reports/projects/hello-agent/staff_report_TEMPLATE.md` and include:
1. **Work Summary** – key contributions, decisions, blockers resolved.
2. **Feelings / Sentiment** – confidence level, morale, notable stressors.
3. **Recommendations** – process/tooling changes, next focus areas.
4. **Place in Project** – how your role interfaces with hello-agent (upstream vs downstream ownership, review cadence, etc.).

## Submission Rules
- Store each report under `reports/projects/hello-agent/staff_reports/<agent>_<date>.md`.
- Reference relevant evidence (commits, audit entries, release summaries).
- Keep prose concise (≤ 1 page). Bullet points encouraged.
- Log completion in `audit/logs/YYYY-MM-DD.md` to preserve compliance traceability.
